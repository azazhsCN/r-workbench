## R Workbench v0.3.0

**问卷效度线开启 + 结构化结果协议 + AI 自动执行**

本版本最重要的工程决策：**全部新增功能零外部 R 包依赖**。EFA 用 base R 与 `stats::varimax` 完整实现，只要装了 R 就能用，无需编译任何扩展包。

---

### ✨ 新增

#### 探索性因子分析（EFA）
- 检验量表**结构效度**：KMO 取样适切性度量、Bartlett 球形检验、因子载荷
- 输出三张学术三线表：
  1. **KMO 与 Bartlett 球形检验**（含极佳/适合/尚可/勉强/不适合 判定）
  2. **方差解释**（特征值、方差解释率、累计解释率）
  3. **旋转后因子载荷矩阵**（动态因子列、共同度、主因子归属）
- **纯 base R 实现**，无需安装 `psych` / `lavaan` / `jsonlite`
- 因子数默认按 Kaiser 准则（特征值 > 1），也可指定

#### 结构化结果协议（`resultSchema.ts`）
- 为 14 种方法定义类型化结果，字段名与 R 端 JSON 一一对应
- 从根上消除"文本 + 固定下标"接口的脆弱性（这是 v0.2.x 多次事故的根源）
- base R 实现 JSON 序列化，可精确保留 `1.6696692e-31` 等极小 p 值

#### AI 自动执行
- AI 生成 R 代码后**默认直接执行**，无需再点一次「执行」
- 状态栏有开关可关闭，回到"先看代码再手动执行"的教学模式
- **产品红线**：自动执行时代码块、三线表、原始输出**始终可见**，随时可接管

### 🔧 修复

发布前审查发现并修复的正确性缺陷：

- **独立样本 t 检验**：「均值差」列显示成了「95% CI 下限」的值（表格与 AI 解读引用的数字互相矛盾）
- **单样本 t 检验**：「95% CI 下限」显示成了 **p 值**、「Cohen's d」显示成了 **CI 上限**
- **R 警告永远无法显示**：`warnings` 字段声明了却从未赋值，卡方期望频数不足等关键统计警告被静默丢弃
- **负特征值导致载荷表整列 NaN 且不报错**：相关矩阵接近奇异或指定因子数接近 p−1 时会发生
- **README 方法数未同步**（13 → 14）
- **打包产物残留 `.old`/`.update` 二进制**（64 MB）

#### EFA 验证亮点
- **独立 oracle 双路复算**：Bartlett 用 `determinant()`、KMO 用 `chol2inv()` —— 与实现走不同求逆路径
- **共同度不变量**：正交旋转不改变 Σ(载荷²)，误差 ≤ 2.2e-16
- **结构效度**：已知 2 因子与 3 因子数据下，题项逐题归并正确
- **变异测试**：KMO 公式改错 → FAIL；因子数硬编码 → **3 条断言 FAIL**（3 因子数据集专为此设计，避免测试判别力不足）
